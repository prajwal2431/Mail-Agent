Mail agent

A personal script that reads the owner's own Gmail on the owner's own computer. It sorts mail, writes a daily summary, and adds Gmail labels. It never deletes mail.

Privacy policy

Mail data is read through the Gmail API and stays on the owner's computer. Nothing is shared, sold, or sent to any other server. The app is used only by its owner.

Google user data is used only to provide the features above, in line with the Google API Services User Data Policy, including the Limited Use requirements.
